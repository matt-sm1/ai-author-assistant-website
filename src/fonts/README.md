# Site fonts (self-hosted)

Latin WOFF2 files from [@fontsource/inter](https://www.npmjs.com/package/@fontsource/inter) and [@fontsource/host-grotesk](https://www.npmjs.com/package/@fontsource/host-grotesk) 5.3.0 (SIL Open Font License).

Loaded via `next/font/local` in `src/lib/fonts.js` so production builds never hit Google Fonts / Turbopack URL parsing failures.
